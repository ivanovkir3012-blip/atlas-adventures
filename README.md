# Атлас приключений — foundation v2

Ветка `foundation-v2` содержит первый этап обновления архитектуры после согласования технического задания 2.0.

## Что сделано в этом этапе

- Добавлена модель выезда с участниками, координатами, погодой, хронологией, заметками, избранным, обложкой и категорийными данными.
- Добавлена локальная IndexedDB-структура для выездов, медиафайлов и настроек.
- Добавлена миграция существующей базы IndexedDB с версии 1 на версию 2 без удаления старых записей.
- Добавлена основа локального хранения медиафайлов (Blob) и статусов будущей облачной загрузки.
- Удалён пункт «Дневник» из основной навигации.
- Обновлены подписи и пустое состояние списка выездов.
- Удаление выезда теперь переводит запись в корзину; предусмотрено восстановление и окончательная очистка записей старше 30 дней.

## Что пока НЕ реализовано

- Интерфейсы всех полей подробной формы.
- Полноценная галерея, выбор обложки и воспроизведение видео.
- Облачная база, объектное хранилище, авторизация и синхронизация устройств.
- QR-подключение устройств.
- Карты, графики статистики, рекорды.
- Экспорт PDF/CSV и управление настройками.

Статусы `queued/uploading/synced/failed` в модели медиа пока являются архитектурной основой; реальный загрузчик ещё не подключён.

## Важное

Текущая ветка — промежуточная разработка, не готовый релиз. Не используй её как единственное хранилище важных данных до завершения облачной синхронизации и тестирования восстановления.

## Запуск и проверка

Нужен Node.js 18+:

1. `npm install`
2. `npm run dev`
3. `npm run build` — проверка TypeScript и production-сборка.
