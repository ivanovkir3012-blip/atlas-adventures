# Атлас приключений — MVP 0.1

## Уже реализовано
- Русскоязычный адаптивный интерфейс в тёмно-зелёной и золотой палитре.
- Навигация по шести разделам.
- Главная страница с количеством сохранённых выездов.
- Полевой журнал: создание, просмотр списка, поиск, фильтр по категории, редактирование и удаление.
- Локальное хранение записей в IndexedDB.
- PWA-манифест и базовый Service Worker.
- Индикатор онлайн/офлайн.

## Ограничения первой версии
Это локальный прототип. Данные хранятся только в браузере текущего устройства. Supabase, Cloudflare R2, QR-привязка устройств, синхронизация, загрузка медиа, корзина на 30 дней, полноценные офлайн-карты и экспорт ещё не подключены. Удаление в этой версии окончательное. Не используй прототип как единственное хранилище важных записей.

## Запуск
Нужен Node.js 18+:
1. npm install
2. npm run dev
3. Открой адрес, который покажет Vite.

Сборка: npm run build.
